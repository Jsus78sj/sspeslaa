# Internet Speed Meter Lite

تطبيق خفيف لعرض سرعة الإنترنت واستهلاك البيانات في شريط الإشعارات.

## المميزات
- عرض السرعة لحظياً (تحميل/رفع) في إشعار دائم، مع خيار فصلهما في إشعارين
- «الإشعار الذكي»: عند انقطاع الاتصال ينتقل الإشعار إلى قناة صامتة بلا أيقونة في شريط الحالة
- فصل استهلاك بيانات الجوال عن الواي فاي (اليوم بالتوقيت المحلي)
- سجل استهلاك 30 يوماً، ومراقبة استهلاك كل تطبيق
- ثلاثة ثيمات (فاتح / داكن / أزرق ليلي)
- إعادة تشغيل الخدمة تلقائياً بعد إقلاع الجهاز (ما لم توقفها)

## الصلاحيات
| الصلاحية | السبب |
|---|---|
| الإشعارات (Android 13+) | عرض إشعار السرعة |
| الوصول إلى بيانات الاستخدام (يمنحها المستخدم يدوياً) | قراءة استهلاك الواي فاي/الجوال والتطبيقات |
| READ_PHONE_STATE (Android 7–9 فقط) | معرّف الشريحة لقياس بيانات الجوال |

لا يطلب التطبيق صلاحية الإنترنت ولا يرسل أي بيانات خارج الجهاز.

## التقنيات
Kotlin + Jetpack Compose + Room + TrafficStats + NetworkStatsManager + WorkManager + DataStore + Navigation Compose

## البناء
- **GitHub Actions**: كل push يبني APK (debug) ويرفعه كـ artifact من تبويب Actions.
- **محلياً**: افتح المشروع في Android Studio، أو ثبّت Gradle 8.6 ونفّذ مرة واحدة
  `gradle wrapper --gradle-version 8.6` لتوليد `gradlew` و`gradle-wrapper.jar`، ثم `./gradlew assembleDebug`.
